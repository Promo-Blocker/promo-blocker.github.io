Privacy Policy for Promoted Post Hider for Reddit

Effective date: October 13, 2026

Promoted Post Hider for Reddit is a browser extension that injects a single stylesheet into reddit.com pages to hide promoted posts.

Data collection

The extension does not collect, store, transmit, or share any data. It has no analytics, no network requests, no background service worker, and no JavaScript. It does not read page content; it only applies CSS rules that hide elements Reddit marks as promoted.

Permissions

The extension declares no Chrome permissions. It requests access to reddit.com pages solely so the stylesheet can be applied there. Chrome displays this as the ability to read and change data on reddit.com, but the extension contains no code capable of reading or sending anything.

Changes

If this policy ever changes, the new version will be published at this same address with an updated effective date.
